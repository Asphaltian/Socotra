# Socotra

Socotra is a UI framework for .NET apps, inspired by s&box and Avalonia.

## Building

You will need the .NET 10 SDK and [Slang](https://github.com/shader-slang/slang/releases), with `slangc` available on your PATH.

```
git clone https://github.com/Asphaltian/Socotra
cd Socotra
dotnet build
```
